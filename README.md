# EQE-Jsc and Voltage-loss analysis calculator

## This web-app is created by Rakesh Suthar, Graduate student, Indian Institute of Technology Delhi (IIT-Delhi), New Delhi, India.

This simple web app calculator to find the integrated current density form the EQE spectra and voltage losses of solar cells. And will be helpful in the photovoltaics community.
Please go though the paper,https://pubs.acs.org/doi/abs/10.1021/acsami.2c18199 If you want to know more about different woltage losses.
Click on this link: https://voltagelossanalysis.streamlit.app/ to access the web app.
