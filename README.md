# EQE–Jsc and Photovoltaic Voltage-Loss Analysis Calculator

A web-based scientific calculator for analyzing EQE-derived short-circuit current density (Jsc) and photovoltaic voltage losses.

## Web Application

Access the calculator here:

https://voltagelossanalysis.streamlit.app/

## About

This application was developed by **Rakesh Suthar** during his graduate studies at the Indian Institute of Technology Delhi (IIT Delhi), New Delhi, India IN 2022-23. Last update: Sept 2026

The tool calculates integrated short-circuit current density from external quantum efficiency (EQE) spectra and performs photovoltaic voltage-loss analysis.

It is intended to provide a simple and accessible analysis tool for researchers working in photovoltaics and solar-cell characterization.

## Current Capabilities

- Upload or paste EQE spectra
- Calculate EQE-integrated Jsc under AM1.5G illumination
- Calculate the Shockley–Queisser Jsc limit
- Calculate Voc,SQ and radiative Voc
- Analyze ΔV1, ΔV2, and ΔV3 voltage-loss components
- Export wavelength-aligned processed calculation data
